# Alder Ridge Information Security Policy

## 1 Access Control

### 1.1 Password Rotation
Passwords must be changed every 90 days. Reused passwords are rejected by the identity system.

### 1.2 Multi-Factor Authentication
Multi-factor authentication is required for all remote access to company systems.

### 1.3 Guest Network
Visitors may use the guest network with a daily access code issued by the front desk.

## 2 Devices

### 2.1 Personal Devices
Personal devices are permitted for accessing company email, provided a screen lock is enabled.

### 2.2 Laptop Encryption
All company laptops must have full-disk encryption enabled before they are issued.

## 3 Incident Response

### 3.1 Reporting Incidents
Suspected security incidents must be reported to the security desk within 24 hours of discovery.

### 3.2 Log Retention
Security logs are retained for 12 months and then deleted.

## 4 Software

### 4.1 Software Installation
Staff may install approved software from the internal software catalog.
